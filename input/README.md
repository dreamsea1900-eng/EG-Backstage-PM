# 這裡是「收件匣」——把這一頁要給 AI 看的東西丟進來

## 怎麼用（超簡單，三步）

1. **丟檔案**：把這一個頁面的資料，全部丟進這個 `input/` 資料夾——
   - 參考圖、設計截圖（`.png` / `.jpg`）
   - 流程圖（截圖，或 `.md` 檔）
   - 規格、欄位清單（`.md` 檔）
   - **幾個檔都行、種類可以混放**，不用先整理成一份
2. **打開工具**：把整包 `EG站後台-PM` 資料夾拖進 Claude Code（或在資料夾裡開終端機執行 `codex`）
3. **說一句話**：打「開始」或直接按 Enter 送出——AI 就會自動讀這裡的檔案，
   先跟你確認「我讀懂了嗎」、問你幾個對焦問題，然後幫你做出 prototype

## 幾個重點

- **這裡是暫存區，可以隨時清空重放。** 做好的頁面會放在各自的資料夾（例如 `BannerManagement/`），
  那個才是成果——你把 `input/` 清空、換下一頁的檔案，都不會動到已經做好的頁面。
- **一次放一頁的材料就好。** 做完一頁清空、再放下一頁。
- **不確定的地方不用先想好。** 文案、API、欄位還沒定，直接寫「待定」，AI 不會亂猜、會留 `TODO` 記號。
- **想改已經做好的頁面？** 也可以把「這次要改的參考」丟進來，AI 會先問你「這批是做新頁、還是改哪一頁」。

## 準備規格的小訣竅（放 `.md` 檔時）

- 用【規格】／【建議】標記：【規格】＝一定要照做；【建議】＝可以讓 AI 依設計規範決定
- 講清楚每個畫面的狀態（空的時候、載入中、出錯、成功）
- 沒定案的就寫「待定」

> 這個 README 只是說明，AI 會自動略過它。放心把你的檔案丟進來就好。
