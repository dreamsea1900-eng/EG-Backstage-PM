# input/ — 本次頁面的素材收件匣

一次只放一頁的材料。這裡可隨時清空；成果會產在獨立頁面資料夾。

## 建議放入

### 修改既有頁面

有的話請提供一種現況介面依據：

- 現有頁面截圖
- 既有 prototype／HTML
- Figma 匯出圖
- 能定位到目標區塊的說明

並提供本次想展示的修改。若沒有截圖，Agent 會依 kit 內的 EG 既有版型製作，
但不會宣稱像素級還原特定舊頁。

### 製作全新頁面

最少只要說清楚：

- 這頁是給誰看
- 想展示什麼功能或想法
- review 時希望操作或看到什麼

欄位、流程、文案或畫面草圖有多少放多少；不需要 API、資料庫或完整工程規格。
Agent 會依既有 EG 版型補齊呈現。也可複製 `templates/SPEC-TEMPLATE.md` 填寫。

## 支援格式

- 規格、欄位、流程：`.md`
- 截圖、流程圖、視覺參考：`.png`、`.jpg`
- 多個檔案可以混放，不必合併

## 重要原則

- 未定內容可寫「待定」，Agent 會使用中性展示假設，不宣稱是正式規則。
- 只有功能想法、沒有 UI 骨架也可以直接製作。
- 未提及的產品能力不加入；版型、排版與標準表單呈現由 Agent 依 EG 慣例完成。
- 要讓 AI 發想產品方案時，請明確寫「概念探索」；否則只補呈現、不補功能。
- `README.md` 本身會被 Agent 略過。
